# AniVerse 🎌

PWA para descubrir y seguir tus animes favoritos.

## ✨ Características
- 🔍 Búsqueda global de anime (Jikan API)
- 🏆 Rankings de anime populares
- 🎨 Modo oscuro / claro
- 🍪 Banner de cookies (RGPD)
- 📱 Instalable como PWA
- 🔐 Autenticación con JWT (próximamente)
- 🐳 Despliegue con Docker Compose

## 🛠 Stack
- **Frontend**: React, React Router, Context API
- **Backend**: Node.js, Express
- **Base de datos**: PostgreSQL (con pgcrypto)
- **Contenedores**: Docker Compose
